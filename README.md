# Projet-SQL-Commercial
## Description du Projet
Ce projet consiste en la conception, la création et la manipulation d'une base de données relationnelle complète pour la gestion des ventes, des clients, des produits et des employés (modèle Northwind).

## Technologies Utilisées
* **SGBD** : SQL Server / T-SQL
* **Outils** : Management Studio (SSMS)

## Structure de la Base de Données
La base comprend 7 tables principales interconnectées :
- `CUSTOMERS` : Gestion des coordonnées clients.
- `ORDERS` & `ORDER_DETAILS` : Suivi des commandes, volumes, prix unitaires et remises.
- `PRODUCTS` & `CATEGORIES` : Catalogue de produits et gestion des stocks.
- `EMPLOYEES` : Organisation interne et hiérarchie.
- `SUPPLIERS` : Réseau de fournisseurs.

## Compétences Mises en Œuvre
- Définition du schéma relationnel (Clés primaires `PK`, contraintes d'intégrité).
- Insertion et structuration de données complexes.
- Écriture de requêtes d'extraction (Jointures, Agrégations, Filtres).
